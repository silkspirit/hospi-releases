# Hospi for Windows

Public installer and automatic-update feed for the Hospi hotel concierge demonstration.

The application source is private. This repository contains release artifacts and this distribution notice only.

Download the Windows x64 installer from Releases. The initial demo is unsigned, so Windows may show a trust prompt. An operator must activate the kiosk before guest check-in or voice sessions can begin.

Updates download automatically and restart the app only after the guest session has ended, pending work has finished and guest details have been cleared.

Maison Alder and its reservations are fictional. Identity checks, payments and physical keys are handled by staff.
